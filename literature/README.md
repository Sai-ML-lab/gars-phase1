# Literature workspace

Keep a reproducible search log and one row per primary paper. Suggested columns:

`paper_id, title, authors, year, venue, DOI_or_URL, peer_review_status,
problem, method, model, dataset, metrics, key_results, limitations,
relevance_to_GARS, full_text_read, notes`

Do not treat AI-generated summaries as primary evidence. Verify claims against
the paper PDF, especially equations, experimental settings, and limitations.
